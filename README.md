# LeihNest

**Gemeinsam nutzen. Einfach organisiert.**

Kamilunavo's German/English web application for closed groups to manage shared equipment, reservations, handovers and returns.

Product domain: `leihnest.de`.

## Scope

- Responsive public website and authenticated workspace.
- Private groups, role-based membership and email-bound invitations.
- Equipment catalogue with quantities, photos, accessories and locations.
- Availability-aware reservations, approvals, handovers and returns.
- Self-hosted deployment; no external hosted backend required.

Implementation is developed on a feature branch. This repository is not a production deployment. No billing or public registration is enabled by this initial commit.
